# telega-fs: заметки для агентов

- Источник правды — `docs/SPEC.md`. Перед изменением поведения сначала правится спека, потом код.
- Никогда не коммитить секреты и сессии: `api_id`/`api_hash`, `*.binlog`, каталоги TDLib, keyring, логи. Если такой файл появился в `git status`, остановиться и сказать пользователю.
- TDLib 1.8.70 собран локально в `./td/tdlib` (не в git). CMake: `-DTd_DIR=$PWD/td/tdlib/lib/cmake/Td`.
- Тесты по умолчанию идут на `LocalDirStore`. Реальный Telegram — только тестовый DC (`use_test_dc`) и только по явной просьбе.
- Документация и комментарии к архитектуре на русском, идентификаторы и сообщения коммитов на английском.
